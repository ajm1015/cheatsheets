Git Field Cheatsheet

🛠 Setup & Init
Initialize a Repository
Create a new local repo in the current directory. Use -b to set the default branch name.
GITgit init
git init -b main          # set default branch name
Clone a Repository
Download a remote repo. Use --depth for a shallow clone (faster, no full history).
GITgit clone <url>
git clone <url> my-folder          # into named dir
git clone --depth 1 <url>          # shallow — latest commit only
git clone --branch dev <url>      # clone specific branch
Set Identity
Set author name and email globally. Omit --global to scope to the current repo only.
GITgit config --global user.name  "Your Name"
git config --global user.email "you@example.com"
Ignore Files
Stop tracking a file that's already committed, then add it to .gitignore.
GIT# Remove from index without deleting on disk
git rm --cached <file>
git rm --cached -r <dir>

# Then add to .gitignore and commit
echo ".DS_Store" >> .gitignore
📦 Core Workflow
Check Status
See what's staged, modified, or untracked. -s is compact one-line-per-file format.
GITgit status
git status -s            # short / compact
Stage Changes
Add files to the staging area. Use -p to stage specific hunks interactively.
GITgit add <file>
git add .                # stage all changes in cwd
git add -p              # interactive hunk selection
git add -u              # stage tracked files only (no new)
Commit
Save staged changes to history. --amend rewrites the last commit — avoid on pushed commits.
GITgit commit -m "message"
git commit -am "message"        # stage tracked + commit
git commit --amend --no-edit    # amend without changing message
git commit --amend -m "new msg"  # amend and rename
⚠ --amend rewrites history. Never amend a commit that's already pushed to a shared branch.
Diff
Show what changed. Without --staged, shows unstaged changes only.
GITgit diff                  # unstaged changes
git diff --staged          # staged vs last commit
git diff HEAD              # all changes vs last commit
git diff main..feature     # between branches
git diff --stat            # summary: files changed, ±lines
Discard / Restore
Undo uncommitted changes. restore is the modern command (git 2.23+). Changes are unrecoverable.
GITgit restore <file>          # discard working tree changes
git restore --staged <file>  # unstage (keep working changes)
git restore .                 # discard all working changes
⚠ Working tree changes are gone permanently — no undo.
Move / Rename Files
Rename or move a tracked file so git preserves history.
GITgit mv old-name.txt new-name.txt
Remove Files
Delete a file and stage the removal. --cached removes from index only (keeps on disk).
GITgit rm <file>              # delete + stage removal
git rm --cached <file>     # untrack, keep on disk
git rm -r <dir>            # remove directory
🌿 Branching & Merging
List / Create Branches
View and create branches. -a includes remote-tracking branches.
GITgit branch                  # list local
git branch -a               # list local + remote
git branch -v               # with last commit info
git branch <name>           # create branch (stay here)
git branch -d <name>        # delete (merged only)
git branch -D <name>        # force delete
⚠ -D force-deletes even unmerged branches — work may be lost.
Switch Branches
switch is the modern way to change branches (git 2.23+). -c creates and switches in one step.
GITgit switch <branch>        # switch to existing branch
git switch -c <new-branch>  # create + switch
git switch -                # switch to previous branch
git switch --detach <sha>  # detached HEAD at commit
Merge
Integrate another branch into the current one. --no-ff always creates a merge commit.
GITgit merge <branch>
git merge --no-ff <branch>       # force merge commit
git merge --squash <branch>     # squash into single staged change
git merge --abort               # bail out mid-conflict
RebaseREWRITES HISTORY
Replay commits on top of another base. -i opens interactive editor to squash, reorder, or edit.
GITgit rebase main               # rebase current branch onto main
git rebase -i HEAD~3           # interactive: last 3 commits
git rebase -i --root           # interactive: entire history
git rebase --continue          # after resolving conflict
git rebase --abort             # bail out completely
⚠ Never rebase commits that exist on a shared remote branch.
Cherry-Pick
Apply a specific commit from another branch onto the current branch.
GITgit cherry-pick <sha>
git cherry-pick <sha1>..<sha2>   # range (exclusive..inclusive)
git cherry-pick --no-commit <sha> # apply but don't commit
git cherry-pick --abort
🌐 Remote
Manage Remotes
Add, view, rename, and remove remote connections.
GITgit remote -v                              # list remotes + URLs
git remote add origin <url>
git remote set-url origin <new-url>
git remote rename origin upstream
git remote remove origin
Fetch
Download remote changes without merging. Safe — never touches your working tree.
GITgit fetch                   # fetch default remote
git fetch origin
git fetch --all             # all remotes
git fetch --prune           # remove deleted remote branches
Pull
Fetch + merge (or rebase) remote changes into the current branch.
GITgit pull
git pull --rebase           # rebase instead of merge
git pull origin main       # explicit remote + branch
git pull --ff-only         # abort if not fast-forward
Push
Upload local commits to remote. -u sets the upstream tracking reference.
GITgit push
git push -u origin <branch>    # push + set upstream
git push --all                 # all branches
git push --tags                # push tags
git push origin --force-with-lease # safe force push
git push origin :<branch>      # delete remote branch
⚠ --force-with-lease is safer than --force: fails if the remote has new commits you haven't fetched.
Tags
Mark release points. Annotated tags (-a) store tagger info; lightweight tags are just pointers.
GITgit tag                              # list all tags
git tag v1.0.0                        # lightweight tag
git tag -a v1.0.0 -m "Release v1.0.0"
git push origin v1.0.0              # push single tag
git tag -d v1.0.0                    # delete local tag
git push origin :refs/tags/v1.0.0   # delete remote tag
📁 Stash
Stash Changes
Temporarily shelve uncommitted changes to get a clean working tree.
GITgit stash                    # stash tracked changes
git stash -u                  # include untracked files
git stash -m "wip: feature"  # named stash
git stash -p                  # interactive / partial stash
Apply / Manage Stashes
pop applies and removes the stash. apply keeps it. drop deletes without applying.
GITgit stash list
git stash pop                # apply latest + remove
git stash apply stash@{1}   # apply specific stash
git stash show -p           # diff of latest stash
git stash drop stash@{0}   # delete a stash
git stash clear              # delete ALL stashes
⚠ git stash clear is permanent — all stash entries are deleted.
⚠ Rewrite / Reset
Reset HEADDESTRUCTIVE
Move HEAD (and optionally the index and working tree) to another commit.
GITgit reset --soft  HEAD~1  # undo commit, keep staged
git reset --mixed HEAD~1  # undo commit, keep unstaged (default)
git reset --hard  HEAD~1  # undo commit + discard all changes
git reset --hard  origin/main # match remote exactly
⚠ --hard permanently discards working tree changes. Cannot be undone without reflog.
Revert (Safe Undo)
Create a new commit that undoes a previous one. Safe for public/shared branches.
GITgit revert <sha>
git revert --no-commit <sha>   # stage revert without committing
git revert HEAD~3..HEAD         # revert a range
Reflog (Recovery)
Every HEAD movement is logged. Use reflog to find and recover "lost" commits after a hard reset.
GITgit reflog                        # show HEAD history
git reflog <branch>               # branch-specific log
git reset --hard HEAD@{3}        # restore to reflog entry
git switch -c recovery <sha>    # branch from a lost SHA
Clean Working TreeDESTRUCTIVE
Delete untracked files and directories. Use -n first to dry-run and preview what will be deleted.
GITgit clean -n       # dry run — preview only
git clean -f        # delete untracked files
git clean -fd       # delete files + untracked dirs
git clean -fdx      # also delete ignored files
⚠ Deleted files are gone — not moved to trash. Always dry-run first with -n.
Purge a File from HistoryDESTRUCTIVE
Remove a file from every commit in history. Requires git-filter-repo (preferred over deprecated filter-branch).
SHELL# Install: pip install git-filter-repo
git filter-repo --path secrets.env --invert-paths

# Then force-push all branches
git push origin --force --all
⚠ Rewrites entire history. All collaborators must re-clone. Rotate any exposed secrets immediately.
🔍 Log / Inspect
Log
Browse commit history. --oneline --graph gives a compact visual branch diagram.
GITgit log
git log --oneline
git log --oneline --graph --all      # visual branch graph
git log --author="name"
git log --since="2 weeks ago"
git log -p <file>               # history of a file with diffs
git log --follow <file>         # follow renames
git log --grep="keyword"        # search commit messages
Show a Commit
Display full details and diff for any commit, tag, or object.
GITgit show <sha>
git show HEAD
git show HEAD:path/to/file     # show file at that commit
git show --stat <sha>         # changed files only
Blame
Show which commit and author last modified each line of a file.
GITgit blame <file>
git blame -L 20,35 <file>    # only lines 20–35
git blame -w <file>          # ignore whitespace changes
git blame -C <file>          # detect moved/copied code
Search Code & History
git grep searches the working tree. -S (pickaxe) finds commits that added/removed a string.
GITgit grep "TODO"                        # search working tree
git grep -n "pattern"                  # with line numbers
git log -S "functionName"             # commits that changed this string
git log -G "regex"                    # commits matching regex in diff
Bisect
Binary search through history to find which commit introduced a bug.
GITgit bisect start
git bisect bad              # current commit is broken
git bisect good v1.2.0     # last known good point
# git checks out midpoint — test, then:
git bisect good             # or: git bisect bad
git bisect reset            # done — return to original HEAD
Worktrees
Check out multiple branches simultaneously in separate directories — no stashing needed.
GITgit worktree add ../hotfix hotfix/123  # new dir + branch
git worktree list
git worktree remove ../hotfix
⚙ Config & Aliases
View Config
Show effective config values and where they're set.
GITgit config --list
git config --list --show-origin    # show which file each comes from
git config user.email              # get single value
Aliases
Create short aliases for common commands.
GITgit config --global alias.st   "status -s"
git config --global alias.co   "switch"
git config --global alias.lg   "log --oneline --graph --all"
git config --global alias.undo "reset --soft HEAD~1"

# Shell alias (run any external command)
git config --global alias.root "!pwd"
Credential Storage
Cache credentials so you're not prompted every push/pull.
GIT# Cache in memory for 15 min (default)
git config --global credential.helper cache

# macOS Keychain
git config --global credential.helper osxkeychain

# Windows Credential Manager
git config --global credential.helper wincred
GPG Signing
Sign commits and tags with a GPG key to prove authorship.
GITgit config --global user.signingkey <key-id>
git config --global commit.gpgsign true   # sign all commits
git commit -S -m "signed commit"          # sign one commit
git log --show-signature                   # verify signatures
Line Endings
Control how git handles CRLF vs LF across platforms.
GIT# Windows: convert to CRLF on checkout, LF on commit
git config --global core.autocrlf true

# macOS/Linux: convert CRLF to LF on commit only
git config --global core.autocrlf input

# Enforce via .gitattributes (recommended)
# * text=auto eol=lf
🧪 Advanced / Esoteric
Contributor Leaderboard
Authors ranked by commit count, merges excluded.
GITgit shortlog -sn --no-merges
Word-Level Diff
Highlight changes word-by-word instead of line-by-line.
GITgit diff --word-diff
Branch From Stash
Pop a stash onto a brand-new branch in one step. Useful when stashed changes conflict with the current branch.
GITgit stash branch <name> stash@{0}
Code Archeology (Pickaxe)
Find every commit that added or removed a string anywhere in history.
GITgit log -p -S "function_name" --all
Total Commit Count
Total commits reachable from HEAD.
GITgit rev-list --count HEAD
Branches by Recency
List local branches sorted by most recent commit.
GITgit for-each-ref --sort=-committerdate refs/heads/ --format='%(refname:short) %(committerdate:relative)'
Fixup + Autosquash
Mark a commit as a fixup of an earlier one, then squash it cleanly via interactive rebase.
GITgit commit --fixup=<sha>
git rebase -i --autosquash <sha>~1          # DESTRUCTIVE — rewrites history
Reuse Recorded Resolution
Have git remember conflict resolutions and replay them on the next equivalent merge.
GITgit config --global rerere.enabled true
git rerere diff                              # show what rerere remembers
Background Maintenance
Have git run gc/prefetch in the background on a schedule.
GITgit maintenance start
git maintenance run --task=prefetch
Sparse Checkout
Check out only a subset of paths from a monorepo.
GITgit sparse-checkout init --cone
git sparse-checkout set apps/web libs/shared
Range Diff
Compare two commit ranges to see what changed between an old and new version of a feature branch (perfect for force-push reviews).
GITgit range-diff main~3..main feat~3..feat
