📦 Intune / Autopilot Field Deployment
Force Intune App Sync (IME Restart)
Restart IntuneManagementExtension service to force immediate app check-in. The loop version is the go-to field trick during setup.
POWERSHELL# One-shot sync
Restart-Service IntuneManagementExtension -Force

# Loop during setup (5 min interval)
while ($true) {
    Restart-Service IntuneManagementExtension -Force
    Write-Host "[$(Get-Date -Format 'HH:mm:ss')] IME restarted"
    Start-Sleep -Seconds 300
}
Force Config / Policy Sync SEPARATE FROM APP SYNC
Policy sync is handled by a different mechanism than app sync. Trigger the MDM scheduled task directly.
POWERSHELL# Trigger MDM policy sync scheduled task
Get-ScheduledTask | Where-Object { $_.TaskName -match 'PushLaunch' } | Start-ScheduledTask

# Or hit device management sync directly
$EnrollID = (Get-ScheduledTask | Where-Object { $_.TaskPath -match 'DMClient' }).TaskPath | Select-Object -First 1
Start-ScheduledTask -TaskPath $EnrollID -TaskName "PushLaunch"
Check Autopilot / ESP Status
What's stuck during ESP — tail the IME log, check enrollment tracking registry.
POWERSHELL# Last 50 lines of IME log
Get-Content "$env:ProgramData\Microsoft\IntuneManagementExtension\Logs\IntuneManagementExtension.log" -Tail 50

# Real-time tail
Get-Content "$env:ProgramData\Microsoft\IntuneManagementExtension\Logs\IntuneManagementExtension.log" -Wait -Tail 20

# ESP tracking state (registry)
Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\Enrollments\*\FirstSync" -ErrorAction SilentlyContinue
Check App Install States (Registry)
What Intune thinks is installed — check Win32App registry for install results.
POWERSHELLGet-ChildItem "HKLM:\SOFTWARE\Microsoft\IntuneManagementExtension\Win32App" -Recurse |
    Get-ItemProperty | Where-Object { $_.Result } |
    Select-Object PSChildName, Result
Check Compliance State Locally

Start-Process "$env:TEMP\MDMDiag\MDMDiagReport.html"
Skip Autopilot OOBE (Escape Hatch) DESTRUCTIVE
At OOBE network screen, Shift+F10 for cmd. Deletes Autopilot profile — device goes to local OOBE.
CMDreg delete "HKLM\SOFTWARE\Microsoft\Provisioning\AutopilotPolicy" /f
shutdown /r /t 0
⚠ Device loses Autopilot profile. Must re-register in Intune afterward.
Re-register Autopilot Profile
Grab hardware hash and upload to Autopilot.
POWERSHELLInstall-Script Get-WindowsAutopilotInfo -Force
Get-WindowsAutopilotInfo -Online
Clear Intune Enrollment (No Wipe) USE CAUTION
Remove MDM enrollment — device stays on Entra but loses Intune management. Re-enrolls automatically on next login if auto-enrollment is on.
POWERSHELL$EnrollPath = "HKLM:\SOFTWARE\Microsoft\Enrollments"
Get-ChildItem $EnrollPath | ForEach-Object {
    $props = Get-ItemProperty $_.PSPath
    if ($props.ProviderID -eq 'MS DM Server') {
        Remove-Item $_.PSPath -Recurse -Force
    }
}
Restart-Computer -Force
🔧 Windows Break-Fix & Diagnostics
Credential / Auth Issues
Nuke cached credentials and WAM token broker cache. Fixes Outlook, Teams, OneDrive auth loops.
POWERSHELL# Nuke all cached credentials
cmdkey /list | ForEach-Object {
    if ($_ -match 'Target:\s+(.+)') { cmdkey /delete:$Matches[1] }
}

# Clear specific Microsoft creds
cmdkey /delete:MicrosoftOffice16_Data:SSPI

# Clear WAM token broker cache
$wamPath = "$env:LOCALAPPDATA\Packages\Microsoft.AAD.BrokerPlugin_cw5n1h2txyewy"
if (Test-Path $wamPath) {
    Get-ChildItem "$wamPath\AC\TokenBroker\Accounts" -ErrorAction SilentlyContinue | Remove-Item -Force
}
BitLocker 
POWERSHELL# Get recovery key locally
(Get-BitLockerVolume -MountPoint "C:").KeyProtector |
    Where-Object { $_.KeyProtectorType -eq 'RecoveryPassword' } |
    Select-Object -Expand RecoveryPassword

# Suspend for 1 reboot (BIOS update, hardware change)
Suspend-BitLocker -MountPoint "C:" -RebootCount 1

# Suspend for 3 reboots (in-place upgrade)
manage-bde -protectors -disable C: -RebootCount 3

# Check encryption status
manage-bde -status C:
Windows Update Stuck / Broken
Reset WU components — stops services, clears caches, restarts, forces detection.
POWERSHELL# Reset Windows Update components
Stop-Service wuauserv, cryptSvc, bits, msiserver -Force
Remove-Item "$env:SystemRoot\SoftwareDistribution" -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item "$env:SystemRoot\System32\catroot2" -Recurse -Force -ErrorAction SilentlyContinue
Start-Service wuauserv, cryptSvc, bits, msiserver

# Force detection
(New-Object -ComObject Microsoft.Update.AutoUpdate).DetectNow()
usoclient StartScan
Reboot Pending Detection
Check all common reboot-pending indicators in one sweep.
POWERSHELL# Check all reboot-pending flags
$checks = @{
    'CBS RebootPending'     = Test-Path 'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Component Based Servicing\RebootPending'
    'WU RebootRequired'     = Test-Path 'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\WindowsUpdate\Auto Update\RebootRequired'
    'PendingFileRename'     = [bool](Get-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Control\Session Manager' -Name PendingFileRenameOperations -ErrorAction SilentlyContinue)
    'SCCM RebootPending'    = [bool](Invoke-CimMethod -Namespace 'root\ccm\ClientSDK' -ClassName CCM_ClientUtilities -MethodName DetermineIfRebootPending -ErrorAction SilentlyContinue)
}
$checks | Format-Table -AutoSize

Temporary Profile Loop Fix
User gets a temp profile on every login. Caused by .bak SID key in ProfileList registry.
POWERSHELL# Find the .bak SID key
Get-ChildItem "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ProfileList" |
    Where-Object { $_.PSChildName -match '\.bak$' }

# Fix: rename .bak key to remove the suffix
# 1. If both S-1-5-21-xxx and S-1-5-21-xxx.bak exist:
#    - Rename S-1-5-21-xxx → S-1-5-21-xxx.old
#    - Rename S-1-5-21-xxx.bak → S-1-5-21-xxx
#    - In the renamed key, set State = 0, RefCount = 0
# 2. Reboot

🔬 Endpoint Forensics & Deep Diagnostics
All Startup Entries
Every program scheduled to run at startup, across run keys and startup folders.
PSGet-WmiObject Win32_StartupCommand | Select Name, Command, Location, User
Last 25 Security Events
Quick text dump of recent Security log entries (most recent first).
CMDwevtutil qe Security /c:25 /f:text /rd:true
NIC Driver Audit
All network adapters with driver version and date — useful for old NIC firmware bugs.
PSGet-CimInstance MSFT_NetAdapter -Namespace root/StandardCimv2 |
  Select Name, InterfaceDescription, DriverVersion, DriverDate
Top 15 Memory Hogs
Processes ranked by working set in MB.
PSGet-Process | Sort-Object WorkingSet64 -Descending |
  Select -First 15 Name, @{N='MB'; E={[math]::Round($_.WorkingSet64/1MB)}}
Secure Wipe Free Space [DESTRUCTIVE]
Overwrite deleted-file space on C: with zeros, ones, and random bytes. Slow on large drives. ADMIN required.
CMDcipher /w:C:\
System File Repair Chain
Run DISM first to repair the component store, then SFC to repair Windows protected files. ADMIN.
CMDDISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow
Active TCP Connections
All established outbound connections with the owning process. Spot beacons.
PSGet-NetTCPConnection -State Established |
  Select LocalAddress, LocalPort, RemoteAddress, RemotePort, OwningProcess |
  Sort RemoteAddress
Elevated Scheduled Tasks
All scheduled tasks that run with highest privileges. Persistence hunting.
PSGet-ScheduledTask | Where-Object {$_.Principal.RunLevel -eq 'Highest'} |
  Select TaskName, TaskPath, State
Boot Configuration Dump
Every boot entry — useful when dual-boot or recovery has been tampered with. ADMIN.
CMDbcdedit /enum all
WinRE Status
Confirm Windows Recovery Environment is enabled and where the WIM lives.
CMDreagentc /info
Volume Shadow Copy Inventory
List all VSS snapshots — recover deleted files or check ransomware deletion. ADMIN.
CMDvssadmin list shadows
Signed Driver List
All third-party signed drivers with manufacturer and version.
CMDwmic path Win32_PnPSignedDriver get DeviceName, DriverVersion, Manufacturer /format:table

}

Stale AD Computers
Domain-joined computers that haven't logged on in 90+ days. Requires RSAT-ADTools.
PSGet-ADComputer -Filter * -Properties LastLogonDate |
  Where { $_.LastLogonDate -lt (Get-Date).AddDays(-90) } |
  Select Name, LastLogonDate
